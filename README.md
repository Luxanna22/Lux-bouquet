# Bouquet Studio 💐

An interactive floral arrangement and love bouquet studio built with React, Vite, TypeScript, and Tailwind CSS.

## 🚀 Getting Started

### Development
Start the local Vite dev server:
```bash
npm run dev
```

### Production Build
Typecheck with TypeScript and build the optimized production bundle:
```bash
npm run build
```

### Preview
Preview the production build locally:
```bash
npm run preview
```

## 📁 Project Structure

- `bouquet_studio.tsx`: Main Bouquet Studio application component and state machine.
- `src/main.tsx`: React application entry point.
- `src/App.tsx`: App wrapper re-exporting Bouquet Studio.
- `src/index.css`: Tailwind CSS entry.
- `vite.config.ts`: Vite build configuration.
- `package.json`: Project dependencies and scripts.
